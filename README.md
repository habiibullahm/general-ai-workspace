# General AI Workspace

A provider-independent general-purpose AI chat workspace. Product requirements, architecture, and implementation guidance are maintained in [`docs/`](docs/).

## Local development

Requires Node.js 20.9 or newer and npm.

```bash
npm ci
npm run dev
```

Available checks: `npm run lint`, `npm run typecheck`, `npm test`, `npm run build`, and `npm run test:e2e`.
